# Evolution_Z

> Top-down survival action · Python + Pygame · Экзаменационная работа по ООП

---

## О проекте

**Evolution Z** — игра в жанре top-down survival action в стилистике MiniDayZ и Zero Sievert.

Игрок исследует сеть заброшенных бункеров секретной программы ЭДЕМ, собирает компоненты вакцины от синтетического вируса и сталкивается с его первоисточником — мутировавшим Носителем Ноль.

Проект разработан как экзаменационная работа по объектно-ориентированному программированию. Архитектура и демонстрация принципов ООП важнее количества контента.

**Длительность прохождения:** 25–35 минут

## Структура игры

```
Бункер А-1  →  Бункер Б-3  →  Лаборатория ЭДЕМ-5  →  ЭДЕМ-7
  гл. 1           гл. 2             гл. 3              Финал
```

| Глава | Локация | Событие | Награда |
|---|---|---|---|
| 1 | Бункер А-1 | Узнать об искусственном происхождении вируса | Компонент вакцины №1 |
| 2 | Бункер Б-3 | Восстановить питание, пережить волну зараженных | Компонент вакцины №2 |
| 3 | Лаборатория ЭДЕМ-5 | Столкнуться с мутантами, найти координаты | Компонент вакцины №3 |
| Финал | ЭДЕМ-7 | Победить Носителя Ноль | Образец крови → вакцина |

### Концовки

- **Хорошая** — все три компонента собраны → вакцина создана → вирус уничтожен
- **Плохая** — не все компоненты собраны → эксперимент провален

## Архитектура

Проект построен по слоистой архитектуре. Каждый слой зависит только от слоёв ниже.

```
project_eden/
├── core/          # базовые классы: GameObject, Entity, Weapon, Item
├── entities/      # конкретные объекты: Player, Zombie, Boss, Bullet
├── systems/       # игровые системы: combat, inventory, quest, save...
├── ui/            # экраны: MainMenu, GameScreen, InventoryUI...
├── data/          # dataclass-структуры данных
└── assets/        # спрайты, звуки, карты, JSON-конфиги
```

### Принципы ООП

**Наследование**
```
GameObject → Entity → Player
                    → Zombie → WalkerZombie / RunnerZombie / SpitterZombie
                    → Boss   → PatientZeroBoss
```

**Инкапсуляция**
```python
entity.take_damage(10)   # правильно — через метод
print(entity.health)     # правильно — через @property
entity._health -= 10     # неправильно — нарушение инкапсуляции
```

**Полиморфизм**
```python
for enemy in world.enemies:
    enemy.update(dt)     # каждый тип — своя логика AI
    enemy.attack(player) # Walker бьёт в ближнем, Spitter плюётся
```

**Композиция**
```python
class Player(Entity):
    def __init__(self):
        self.inventory = Inventory()    # has-a
        self.health    = HealthComponent()
        self.hunger    = HungerComponent()
```
