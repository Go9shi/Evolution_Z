# Evolution_Z

> Top-down survival action · Python + Pygame · Экзаменационная работа по ООП

---

## О проекте

**Evolution Z** — игра в жанре top-down survival action в стилистике MiniDayZ и Zero Sievert.

Игрок исследует заброшенный бункер секретной программы ЭДЕМ, собирает компоненты вакцины
от синтетического вируса и сталкивается с его первоисточником — мутировавшим Носителем Ноль.

Проект разработан как **экзаменационная работа по объектно-ориентированному программированию**.
Архитектура и демонстрация принципов ООП важнее количества контента.

> **Скоуп v1 (фактический):** один игровой уровень, проходимый от старта до победы.
> Мульти-главы, TMX-карты, аудио, спрайты и ветвящиеся концовки — **вне скоупа v1**
> (см. раздел [«Вне скоупа v1»](#вне-скоупа-v1)).

|---|---|
| `WalkerZombie` | Медленный, высокий HP, ближний бой |

## Оружие

Все виды наследуются от `core.weapon.Weapon` и переопределяют `fire()` (полиморфизм);
параметры — в `assets/data/weapons.json`.

| Класс | Особенности |
|---|---|
| `Pistol` | Стартовое оружие; одиночный выстрел |
| `Rifle` | Одиночный выстрел; выше скорострельность, ниже урон |
| `Shotgun` | Несколько дробинок веером за выстрел; низкая скорострельность |

> В v1 игрок экипирован пистолетом; `Rifle`/`Shotgun` доступны через конфигурацию
> (`weapons.json`) и конструируемы — переключение оружия в бою вне скоупа v1.

## Архитектура

Слоистая архитектура; каждый слой зависит только от слоёв ниже.

```
Evolution_Z/
├── core/          # базовые классы: GameObject, Entity, Weapon, Item
├── entities/      # конкретные объекты: Player, Zombie, Boss, Bullet, weapons/
├── systems/       # игровые системы: combat, inventory, quest, save, event_bus...
├── ui/            # экраны: MainMenu, GameScreen, PauseMenu, InventoryUI...
├── data/          # dataclass-структуры данных
└── assets/data/   # JSON-конфиги: weapons, enemies, items, quests, dialogues, lore
```

### Принципы ООП

**Наследование**
```
GameObject → Entity → Player
                    → Zombie → WalkerZombie / RunnerZombie / SpitterZombie
                    → Boss   → PatientZeroBoss
Weapon → Pistol / Rifle / Shotgun
```

**Инкапсуляция**
```python
entity.take_damage(10)   # правильно — через метод
print(entity.health)     # правильно — через @property
entity._health -= 10     # неправильно — нарушение инкапсуляции
```

**Полиморфизм**
```python
for enemy in enemies:
    enemy.update(dt, walls, player)   # каждый тип — своя логика AI

weapon.fire(pos, direction)           # Pistol/Rifle — 1 пуля, Shotgun — веер
```

**Композиция**
```python
class Player(Entity):
    def __init__(self, ...):
        self._inventory = Inventory()        # has-a
        self.health     = HealthComponent()
        self.hunger     = HungerComponent()
        self.experience = ExperienceComponent()
```

## Вне скоупа v1

Следующее **описано в нарративном замысле, но не реализовано** в текущей версии:

- Четыре главы и переходы между локациями (игра проходит на одном уровне)
- Загрузка карт из Tiled `.tmx` (стены задаются в коде)
- Ветвящиеся концовки (хорошая/плохая) — есть единый экран Victory
- Аудио (SFX/музыка)
- Спрайты (рендер выполняется примитивами pygame)
- Переключение/подбор оружия в бою, перезарядка
