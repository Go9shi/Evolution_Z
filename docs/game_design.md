## Название

**Evolution Z**

Аббревиатура ЭДЕМ — внутриигровое название секретной программы биологических исследований.  
Для игрока это одновременно место действия, антагонист и ответ на вопрос «что здесь произошло».

---

## Жанр

**Top-down survival action**

- Вид сверху, движение по всем 8 направлениям
- Акцент на исследовании и выживании, не на аркадном экшене
- Темп: напряжённый, но вдумчивый — патроны ограничены, каждый бой важен
- Без процедурной генерации: авторские карты с ручной расстановкой контента

| Игра | Что взято |

| **Hotline Miami** | напряжение от каждого столкновения, читаемые спрайты |
| **The Last of Us** | нарратив через окружение, найденные записки и терминалы |

Общий тон: **тихий апокалипсис**. Не зомби-аркада, а история о том, что люди сделали сами с собой.

## Цель

### Цель игрока (нарративная)
Проникнуть в сеть заброшенных бункеров секретной программы ЭДЕМ,  
собрать три компонента вакцины от синтетического вируса  
и уничтожить его первоисточник — мутировавшего Носителя Ноль.

### Цель игрока (геймплейная)
- Пройти 4 локации: **Бункер А-1 → Бункер Б-3 → Лаборатория ЭДЕМ-5 → ЭДЕМ-7**
- Выжить, управляя ресурсами: здоровье, патроны, инвентарь
- Развить персонажа через систему опыта и дерево навыков
- Раскрыть историю через сюжетные записки и терминалы

### Цель проекта (учебная)
Продемонстрировать принципы ООП на Python + Pygame:
- **Наследование** — иерархия `GameObject → Entity → Player / Zombie / Boss`
- **Полиморфизм** — единый интерфейс `update()` / `attack()` для всех врагов
- **Инкапсуляция** — приватные поля `_health`, свойства и методы доступа
- **Композиция** — `Player` содержит `InventorySystem`, `SkillTree`, `Weapon`

### Победное условие
- **Хорошая концовка**: все 3 компонента собраны → вакцина создана → вирус уничтожен
- **Плохая концовка**: не все компоненты собраны → эксперимент провален

## Основные механики (MVP)

| Механика | Описание |
|---|---|
| Передвижение | WASD, 8 направлений, анимация ходьбы |
| Камера | следует за игроком, плавный сдвиг |
| Коллизии | стены, двери, объекты окружения |
| Оружие | пистолет / дробовик / винтовка |
| Стрельба | пули как объекты, хитбоксы |
| Здоровье | HP-бар, аптечки, регенерация через навыки |
| Инвентарь | сетка слотов, подбор / использование |
| Опыт и уровни | XP с врагов, рост характеристик |
| Дерево навыков | 3 ветки: выживание / боёвка / разведка |
| Система квестов | основные и побочные, трекер целей |
| Сюжетные записки | найденные PDA, терминалы, дневники |
| Враги | 3 класса зомби + финальный босс |
| Сохранение / загрузка | JSON, слоты сохранений |

## Враги

### Зомби

| Класс | HP | Скорость | Поведение |
|---|---|---|---|
| `WalkerZombie` | высокий | низкая | патруль → преследование при виде |
| `RunnerZombie` | низкий | высокая | агрессивный рывок, группы |
| `SpitterZombie` | средний | низкая | дальняя атака кислотой |

### Финальный босс

**PatientZeroBoss** — Носитель Ноль  
Три фазы боя с изменением поведения при снижении HP:
- Фаза 1: ближний бой + призыв уокеров
- Фаза 2: ускорение + кислотные лужи
- Фаза 3: берсерк, усиленный урон

## Структура глав

| Глава | Локация | Ключевое событие | Награда |
|---|---|---|---|
| 1 | Бункер А-1 | узнать об искусственном происхождении вируса | Компонент вакцины №1 |
| 2 | Бункер Б-3 | восстановить питание, пережить волну зараженных | Компонент вакцины №2 |
| 3 | Лаборатория ЭДЕМ-5 | встретить мутантов, найти координаты ЭДЕМ-7 | Компонент вакцины №3 |
| Финал | ЭДЕМ-7 | победить Носителя Ноль | Образец крови → вакцина |

## Продолжительность

**25–35 минут** полного прохождения при знании маршрута.  
Первое прохождение с исследованием: ~45–50 минут.

---

## Вне скоупа (не реализуется в v1)

- Крафт предметов
- Строительство базы
- Мультиплеер
- Процедурная генерация карт
- Торговля / экономика
